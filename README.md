# Плагин Code Style Critic для Visual Studio Code

Реализация лабораторной работы по ИСРПО.

* **Целевая IDE:** Visual Studio Code (поддержка ОС Linux / Windows)

---

## 💻 Общее описание проекта
Плагин в реальном времени оценивает качество, стиль кода на языках с и с++. Архитектура разделяется на две части: вся логика анализа файлов (подсчет строк, проверка комментариев) пишется как обычная консольная программа на с++, а сам плагин для VS Code выступает в роли UI-интерфейса - он перехватывает событие сохранения сохранения .c или .cpp файлов, передает его путь в с++ бэкенд и выводит вернувшийся вердикт на экран в уведомлении.

Полная техническая документация и история изменений находятся в каталоге `docs/`.

## 📥 Как скачать и установить (Инструкция)

### 1. Клонирование репозитория
```bash
  git clone https://github.com/Tsygankova-Maria/Extension-for-vsCode-ISRPO-lib.git
```

### 2. Подготовка бэкенда (C++)
Перейдите в папку проекта и скомпилируйте аналитическое ядро под вашу операционную систему:
* **Для Linux:** 
  ```bash
  g++ -O3 main.cpp -o main && chmod +x main
  ```
* **Для Windows:** 
  ```bash
  g++ -O3 main.cpp -o main.exe
  ```

### 3. Сборка плагина
1. Установите необходимые зависимости для работы TypeScript-интерфейса:
   ```bash
   npm install
   ```
2. Принудительно соберите файлы расширения командой esbuild:
   ```bash
   npx esbuild src/extension.ts --bundle --outfile=out/extension.js --platform=node --external:vscode
   ```

## 🚀 Как использовать плагин

1. Откройте проект в VS Code и нажмите клавишу **F5** (или перейдите в меню *Run and Debug* и нажмите кнопку запуска).
2. Среда разработки автоматически откроет новое экспериментальное окно с заголовком `[Extension Development Host]`.
3. В этом новом окне откройте любую вашу рабочую папку с исходным кодом или просто создайте тестовый файл (например, `test.cpp`).
4. Напишите код и нажмите комбинацию клавиш **Ctrl + S** (Сохранить).
5. При каждом сохранении плагин будет автоматически вызывать C++ бэкенд и мгновенно выводить вердикт о качестве вашего Code Style во всплывающем окне в правом нижнем углу экрана!
