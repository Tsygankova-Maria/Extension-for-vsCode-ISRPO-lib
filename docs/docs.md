# Общее описание архитектуры решения

## 1. Концепция и назначение
Проект представляет собой инструмент статического анализа, который в реальном времени оценивает качество, стиль кода на языках с и с++. Система спроектирована по гибридному модульному принципу для оптимизации производительности файлового ввода-вывода и переиспользования существующего опыта разработки на C++.


## 2. Разделение архитектуры
Архитектура системы четко разделяется на две части:

1. **Вычислительное ядро (Бэкенд на C++):** Вся логика анализа файлов (подсчет строк, проверка комментариев, поиск магических чисел, валидация именования по Google Style и проверка фигурных скобок) пишется как обычная консольная программа на с++. Для высокой скорости работы программа считывает файлы поблочно буфером в 4 Кб и функционирует исключительно на стековой памяти без динамических аллокаций.

2. **Интеграционный модуль (Клиент на TypeScript):** Сам плагин для VS Code выступает в роли UI-интерфейса. Он не выполняет тяжелых вычислений, а лишь обеспечивает интеграцию с редактором через официальный VS Code Extension API.


## 3. Процесс взаимодействия модулей
* UI-интерфейс перехватывает событие сохранения сохранения .c или .cpp файлов.
* Скрипт считывает абсолютный путь к сохраненному файлу на диске.
* Путь передается в с++ бэкенд в качестве аргумента командной строки через системный вызов дочернего процесса Node.js.
* Консольная программа на C++ считывает файл, вычисляет метрики, выбирает ироничный вердикт и выводит его в стандартный поток `stdout`.
* UI-интерфейс перехватывает этот поток и выводит вернувшийся вердикт на экран в уведомлении среды разработки.


# Описание программных функций main.cpp

Согласно архитектуре, разделенной на две части, функции распределены по соответствующим программным модулям:

## Часть 1: Консольная программа на C++ (Логика анализа)

### 1. `HasSubstring`
* **Описание:** Низкоуровневый поиск вхождения одной строки в другую (C-string) без использования динамической памяти.
* **Параметры:** `const char* source` (где искать), `const char* target` (что искать).
* **Пример вызова:**
  ```cpp
  bool found = HasSubstring("int value = 5;", "int"); // true
  ```

### 2. `IsBadConstant`
* **Описание:** Проверяет константы на наличие префикса `k` по правилам стиля.
* **Параметры:** `const char* line` (строка кода).
* **Пример вызова:**
  ```cpp
  bool err = IsBadConstant("const int limit = 10;"); // true
  ```

### 3. `IsBadFunctionName`
* **Описание:** Проверяет, начинается ли имя функции с заглавной буквы.
* **Параметры:** `const char* line` (строка кода).
* **Пример вызова:**
  ```cpp
  bool err = IsBadFunctionName("void runTest() {}"); // true
  ```

### 4. `IsBadVariableName`
* **Описание:** Проверяет переменные на отсутствие заглавных букв (контроль snake_case).
* **Параметры:** `const char* line` (строка кода).
* **Пример вызова:**
  ```cpp
  bool err = IsBadVariableName("int testCounter = 0;"); // true
  ```

### 5. `CountMagicNumbers`
* **Описание:** Сканирует кодовую строку на наличие захардкоженных чисел (кроме 0 и 1).
* **Параметры:** `const char* line` (строка кода).
* **Пример вызова:**
  ```cpp
  int count = CountMagicNumbers("if (status == 404)"); // 1
  ```

## Часть 2: Расширение VS Code (UI-Интерфейс)

### 1. `activate`
* **Описание:** Регистрирует перехватчик сохранения файлов и управляет жизненным циклом UI-компонентов.
* **Параметры:** `context: vscode.ExtensionContext`.
* **Пример вызова:** Вызывается автоматически средой IDE при старте.
